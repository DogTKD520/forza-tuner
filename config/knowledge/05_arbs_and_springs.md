# Anti-Roll Bars (ARBs)
ARBs only activate in corners. They resist side-to-side roll. Stiffer ARB on one end = that end loses grip first. Stiffer front ARB -> understeer. Stiffer rear ARB -> oversteer.
Starting point: Max out both ARBs, then soften until the car lands in its balance window (mechanical balance 0.52-0.65). Soften the end with the problem. High-power RWD often requires softer rear to fight oversteer.
Off-road / rally exception: start soft, not maxed.

# Springs
Softer springs absorb bumps but allow body roll and bottoming out. Stiffer springs resist compression but don't absorb bumps. Stiffer front = understeer. Stiffer rear = oversteer.
Heavier end of the car needs stiffer springs to hold its weight.

# Ride Height
Lower is better for center of gravity, but reduces suspension travel. If you bottom out, suspension stops working and grip drops to zero. 
Common starting point: Start at minimum.
Off-road / rally exception: Start high (near max).
